# 🧪 ALGOLAB
### Interactive Data Structures and Algorithms Learning Platform

**Learn. Visualize. Code. Understand.**

ALGOLAB is an interactive web-based learning platform designed to help students understand Data Structures and Algorithms (DSA) through visual demonstrations, algorithm exploration, and hands-on coding.

The platform aims to bridge the gap between theoretical concepts and practical implementation by allowing students to explore algorithm behavior, understand execution steps, and develop stronger problem-solving skills.

---

## 🎯 Project Objectives

- Make Data Structures and Algorithms easier to understand.
- Visualize how algorithms operate step by step.
- Help students connect programming code with algorithm behavior.
- Explore pathfinding techniques through interactive mazes.
- Build a foundation for code tracing and practical algorithm learning.
- Provide a beginner-friendly environment for learning DSA.

---

## ✨ Key Features

### 1. 📊 Algorithm Visualizer
Explore algorithm behavior through interactive visual representations.

- Step-by-step algorithm visualization
- Playback controls
- Animation speed control
- Reset and replay functionality
- Bubble Sort visualization

### 2. 💻 Code Lab
A dedicated interface designed for writing and exploring code.

- Code editor interface
- Java programming language selection
- Algorithm code templates
- Console output interface
- Variable and execution-state inspection interface

**Development note:** Actual Java execution and genuine source-code tracing are planned capabilities and should be considered available only after implementation and testing.

### 3. 🧠 Algorithm Explorer
Explore Data Structures and Algorithms through an organized learning interface.

Planned learning categories include:

- Sorting Algorithms
- Searching Algorithms
- Stack and Queue
- Linked Lists
- Trees and Binary Search Trees
- Graph Algorithms
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

### 4. 🧩 Maze Lab
Explore maze generation and pathfinding algorithms through interactive visualizations.

- Maze generation
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Animated path exploration
- Path reconstruction

Future enhancements may include Dijkstra's algorithm, A* search, and maze-result saving.

## 🚀 Getting Started

Follow these steps to run ALGOLAB locally.

### Prerequisites

- A modern web browser
- Visual Studio Code or another code editor
- Git (optional, for cloning the repository)

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Preetpal10/ALGOLab.git
```

**2. Navigate to the project directory**

```bash
cd ALGOLab
```

**3. Open the project**

Open the project folder in Visual Studio Code.

**4. Run the application**

Open `frontend/index.html` using the Live Server extension in VS Code.

Alternatively, open the HTML file directly in your browser if the current features support it.

**5. Explore ALGOLAB**

Navigate through the available pages to explore the algorithm visualizer, learning interface, and Maze Lab.

## 🔒 Security and Reliability

ALGOLAB's planned code-execution functionality requires a secure execution environment.

- User-submitted code must not execute directly inside the trusted application server.
- Execution should have appropriate time, memory, and resource limits.
- Backend services should validate requests and handle errors safely.
- Database queries should use parameterized statements.
- User passwords should be stored using secure password hashing.

These protections must be implemented and tested before public code execution is enabled.
