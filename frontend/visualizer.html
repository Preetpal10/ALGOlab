Algorithm Explanation

Bubble Sort repeatedly steps through the array, compares each pair of adjacent elements, and swaps them if they are in the wrong order. This process repeats until no swaps are needed, meaning the array is sorted. Larger elements "bubble" toward the end of the array on each pass.

Complexity

Case Time Complexity
Best Case O(n)
Average Case O(n²)
Worst Case O(n²)
Space Complexity
O(1) — sorts in place
